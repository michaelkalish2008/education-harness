How to read this

This is a radial hierarchy, not a statistical projection. Broad standards occupy inner spherical shells; narrower descendants move outward. Angular sectors and color show subject. Every faint line is a direct parent–child code relationship, and selecting a node brightens its branch. Node size shows hierarchy degree. Lines do not claim prerequisites or learning order.
